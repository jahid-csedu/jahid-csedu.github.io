## NewzGator

Personal news product for Bangladeshi publishers, live at [newzgator.com](https://www.newzgator.com). I built the ingestion pipeline, the reader API, the operations console, and the load tests.

Publishers are crawled on a schedule. Links survive a broker outage through a transactional outbox, then a scraper fans each article out for category, summary, and clustering. Bengali text is classified with an ONNX model when the URL does not already name the section. Headlines are embedded into PostgreSQL with pgvector so the same story across papers becomes one cluster, and the feed shows only the lead article. Summaries use Groq, with Gemini as fallback.

The reader API serves search, related stories, trending clusters, and recommendations from clicks, bookmarks, comments, and reactions. Sign-in is Google, Facebook, or X. An admin console manages publisher scrape rules and pipeline health.

Java, Spring Boot, PostgreSQL, pgvector, RabbitMQ, OpenTelemetry, Gatling.
